ReClaim — Research Validation Tool

📋 What Is ReClaim?

ReClaim takes any research paper and independently verifies its claims using live scientific tools — not just language model knowledge. It tells you what AI can confirm, what it cannot, and why.

⚙️ How It Works

1
Upload — Drop any research PDF.
2
Custom Questions — Optionally add your own micro-questions before running.
3
Extract — Top claims and findings are identified.
4
Tool Verification — ToolUniverse searches PubMed, ArXiv, Semantic Scholar and 900+ sources independently.
5
Coherence Score — Internal consistency, methodology, and citation quality scored 0–100.
6
Deep Verification — If score >90, optionally run counter-claim search or stricter re-verification.

🏗️ Architecture

Frontend → Flask → Gemini CLI → ToolUniverse MCP (900+ tools) Output streams live via Server-Sent Events (SSE)

🔁 Swappable Backends

ToolUniverse is the default engine. ReClaim is designed to be backend-agnostic — swap via .env.

⚠️ Known Limitations

ReClaim verifies literature-backed claims. It cannot verify claims requiring proprietary datasets, custom simulations, or computational experiments. It surfaces this gap honestly.

🔍 Verification Statuses

verified partially-verified unverifiable contradicted 🟣 custom
