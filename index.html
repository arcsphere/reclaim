ReClaim — Research Validation Tool

📋 What Is ReClaim?

ReClaim supports two workflows: validating a paper against external research, and comparing how faithfully a target paper preserves answers and claims from a source paper.

⚙️ Modes

1
Literature Validation — Upload one paper and verify its claims using Gemini CLI + ToolUniverse.
2
Comparison Mode — Upload source and target PDFs, optional claims / CSV / intermediate files, and compare answers question-by-question.

🏗️ Architecture

Frontend → Flask/FastAPI backend → Gemini CLI / comparison pipeline Streaming output via Server-Sent Events (SSE)

🔍 Statuses

verified partially-verified unverifiable contradicted match missing mismatch

🛠️ Current Endpoints

POST /analyze → literature validation POST /compare → source vs target comparison
